# PWP Panel Assembly Layout Design — Case Study Data

Supplementary data for the paper:

> *[Paper title], [Authors], [Journal], [Year]. DOI: [to be added upon publication]*

This repository provides the case-study results of the proposed two-stage
evolutionary algorithm (EA) for prefabricated wall panel (PWP) assembly layout
design and manufacturing, including the resulting BIM models, the input data of
the two real-world cases, the multi-run statistical results, and the manual
(human-designer) reference designs used for comparison.

## Key results

| Case | Manual design | Automated design (10 runs) | Material saving |
|---|---|---|---|
| 1 | 10 PWP bodies, 26.8 m | 8 bodies (all runs), 21.61 ± 0.22 m (best 21.46 m) | 19.4 ± 0.8% |
| 2 | 7 PWP bodies, 18.7 m | 6 bodies (all runs), 16.41 ± 0.07 m (best 16.23 m) | 12.3 ± 0.4% |

The number of PWP bodies is identical across all ten runs for both cases, and
the automated design saves approximately 16% of PWP material on average
compared with the manual design.

## Notes

- The `.rvt` models were created with Autodesk Revit [VERSION]; they can be
  opened with the same or a newer version of Revit.
- The manual designs were produced by professional designers using an
  Excel-based workflow (deterministic; reported as single values).
- The automated results were obtained with the two-stage EA described in the
  paper (ten independent runs per case with different random seeds).
